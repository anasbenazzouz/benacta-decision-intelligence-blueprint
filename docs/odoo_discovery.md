## 1. Findings that shape the design

| Observed | Consequence |
|---|---|
| `stock.valuation.layer` does not exist on this version. | Cost attribution reads valuation from `stock.move` (`value`, `price_unit`, `account_move_id`). No adapter may assume the Odoo 13 to 18 layer model. |
| The `delivery` module is not installed (`delivery.carrier` missing). | FREIGHT-001 is modelled at order and delivery level with a rebillable freight service product and a contract clause. Installing `delivery` requires explicit approval. |
| `sale.order.line.purchase_price` is absent (`sale_margin` not installed). | There is no line-level cost snapshot in Odoo. Realised cost must come from valued stock moves, otherwise the result is UNDETERMINED. |
| No product category uses perpetual valuation (observed: standard/periodic). | Existing data produces no valuation entries. The sandbox company needs its own category configuration; existing categories are not modified. |
| No product is storable (`is_storable` false everywhere). | Existing orders generate no valued deliveries. COST-001 cannot be demonstrated on existing data. |
| No posted COGS journal item exists. | Gross margin on existing data can only be a management proxy, never a reconciled closing margin. |
| No payment method line has an outstanding account. | Payments create no journal entry and invoices stay `in_payment` until bank reconciliation. This is standard Odoo 18+ behaviour, not a platform fault. |
| A single company exists (Benacta). | No sandbox company exists yet, so the Odoo write guard blocks every seed. |
| One active currency (EUR); no dated exchange rates. | The foreign currency negative control runs in fixtures until a currency is authorised in the sandbox. |
| The API key belongs to a user with administrator groups. | Acceptable for discovery. Before automated ingestion, a dedicated bot user with read-only rights should own the ingestion key. |
| No custom outgoing mail server is configured. | Odoo Online can still send mail through its default service. Seeds must disable tracking and notifications and must use non-deliverable partner addresses. |
| E-invoicing modules are installed (Peppol proxy state: not_registered). | The seed must verify the sandbox company is not registered for e-invoicing before posting invoices. |
| Direct PostgreSQL access is not offered by Odoo Online. | ODOO_READ_DSN stays unset; ingestion uses the JSON-2 read adapter. |
